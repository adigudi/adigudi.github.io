Returns Defect Triage Agent

A Claude agent reads each return (customer reason, warehouse note, item photo), grades how likely it is to be a production defect, and routes it: vendor credit, human review, or no action. Below is real agent output on a sample batch.

All 20 returns below are synthetic, written by me to stress-test the grading logic, and deliberately defect-heavy so the interesting cases are visible. No Cuts data was used. Point the same engine at a real returns export and it produces this exact report on live data.

3Route it 70%+ goes to the vendor credit file. 40 to 69% queues for human review. Below 40% closes as customer preference.
